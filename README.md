# 📚 Python Library Management System

A simple Library Management System written in Python.

This project was created as a practice exercise for learning Python modules, packages, and package installation using pip.

## ✨ Features

- Add a new book
- Remove a book
- Search for a book
- Show all books
- Simple interactive menu
- Python package structure
- Local package installation using pip
